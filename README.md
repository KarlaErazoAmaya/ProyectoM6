# Expansión de los asentamientos humanos y transformación del uso de suelo en la Ciudad de México

Proyecto de análisis documental y geoespacial mediante MongoDB.

## Objetivo

Analizar las transformaciones de uso de suelo hacia asentamientos
humanos en la Ciudad de México mediante MongoDB, identificando los
usos de suelo de origen, la superficie y tasa de cambio asociadas,
así como su distribución espacial.

## Estructura del repositorio

- `data/`: datos originales y procesados.
- `scripts/`: scripts de carga, transformación y análisis.
- `docs/`: documentación del modelo y diccionario de datos.
- `evidencias/`: capturas de las pruebas realizadas.
